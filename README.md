# QUANTUM-ETROPY (DOS)
tools dos. atau serangan mengunakan teknik dos. dan sudah di lengkapi fitur user agent, 

pakai format https/https
```bash
misal
https://target.com
```
## Persyaratan

- Python 3.9 atau lebih baru
- Git

Cek versi:

```bash
python --version
git --version
```

## Instalasi

### 1. Clone repo

```bash
git clone https://github.com/xyxx-egx/botnet-DOS.git
cd botnet-DOS
```

## Cara run

```bash
python Dos.py
```

Di Linux / macOS, kalau `python` tidak dikenali:

```bash
python3 Dos.py
```

## Update

```bash
git pull
```

## Troubleshooting

| Masalah | Solusi |
|---|---|
| `ModuleNotFoundError` | Install library yang disebut di error: `pip install nama-library` |
| `python: command not found` | Pakai `python3` atau install Python |
