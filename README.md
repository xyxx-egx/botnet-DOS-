# QUANTUM-ETROPY (DOS)

Deskripsi singkat script: apa fungsinya dan untuk apa dipakai.

## Persyaratan

- Python 3.9 atau lebih baru
- Git

Cek versi:

```bash
python --version
git --version
```

## Instalasi

### 1. Clone repo

```bash
git clone https://github.com/xyxx-egx/botnet-DOS.git
cd botnet-DOS
```

### 2. Install library yang dibutuhkan

Kalau script memakai library tambahan, install dulu (ganti sesuai kebutuhan):

```bash
pip install nama-library
```

Kalau script hanya memakai library bawaan Python, langkah ini dilewati.

## Cara Menjalankan

```bash
python Dos.py
```

Di Linux / macOS, kalau `python` tidak dikenali:

```bash
python3 Dos.py
```

## Update

```bash
git pull
```

## Troubleshooting

| Masalah | Solusi |
|---|---|
| `ModuleNotFoundError` | Install library yang disebut di error: `pip install nama-library` |
| `python: command not found` | Pakai `python3` atau install Python |
